# bug tracker app

this is full stack bug tracker and project management app built using mern stack (mongodb, express, react, nodejs). i made this to track project issues, bugs and tasks in one place like jira.

## what this app can do

- user login and register with jwt token and roles (developer, admin, project manager)
- create new projects and invite team members using their email
- create tickets for bug, feature request or task with priority (low, medium, high, critical)
- kanban board with drag and drop to move ticket between to do, in progress and done
- switch between kanban board view and normal list view anytime
- search ticket by keyword and filter by status, priority or assignee
- click any ticket to edit details, delete ticket or add comments with team

## tech used

- frontend: react, vite, tailwind css, react router, @hello-pangea/dnd
- backend: nodejs, express, mongoose, jsonwebtoken, bcryptjs
- database: mongodb atlas
- hosting: vercel for frontend and render for backend
